# Design notes (historical)

Working briefs and reports written while the suite was built with several
parallel agents (2026). They record intent and findings at the time; the code
and README are authoritative where they differ. Paths such as
"(working notes)" referred to a temporary workspace that no longer exists.

- [edu-features.md](edu-features.md): shared rules for the education features
  wave (permissions contract, i18n workflow, conventions).
- [writer-converters.md](writer-converters.md): DOCX/ODT converter design for
  the TipTap writer.
- [diagram-editor.md](diagram-editor.md): replacing draw.io with our maxGraph
  editor.
- [sheet-engine.md](sheet-engine.md): spreadsheet engine evaluation (Univer
  kept; charts and pivots added).
- [ui-audit.md](ui-audit.md): UI consistency audit that led to the shared app
  frame (work packages WP1–WP7).
- [review-2026-09/](review-2026-09/): full app review (September 2026) — every
  finding with steps and the fix that followed; useful as a regression
  checklist.

Translation sources used during development are in `scripts/i18n/sources/`.
